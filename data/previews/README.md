# Outfit pictures for the installer window

`install.ps1` shows `data/previews/<id>.jpg` on each outfit's card (ids: the table in the main README, e.g. `158.jpg`,
`27.jpg`). Any size works (portrait looks best; the picture is fitted into the card). An outfit without a picture shows
"no preview".

설치 창의 의상 카드에는 `data/previews/<번호>.jpg`가 표시됩니다(번호는 README 표, 예: `158.jpg`, `27.jpg`).
크기는 상관없고 세로 사진이 잘 맞습니다. 사진이 없는 의상은 "미리보기 없음"으로 나옵니다.
